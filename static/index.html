添加账号

怎么拿 token：浏览器登录 www.workbuddy.cn → F12 打开开发者工具 → Network 面板 → 随便点一个页面操作，找到任意 /v2/ 开头的请求 → 在 Request Headers 里复制 Authorization 中 Bearer 后面的部分。
用手机扫码，在手机上粘贴 token 完成添加
二维码 10 分钟内有效，且只能提交一次。手机需要和这台设备在同一个局域网内；软路由部署时用软路由的局域网 IP 访问控制台，二维码会自动用这个地址。
官方登录

点下面按钮，后台静默打开官方登录页，二维码直接显示在这里，用手机微信扫一下就行，不会弹任何窗口。

扫码成功后账号自动加入列表，整个过程不需要你复制粘贴任何东西。
