WorkBuddy 多账号签到助手  v1.0.0
==================================================

一、启动
--------------------------------------------------
双击 wb-checkin.exe，会弹出一个黑色命令行窗口，同时自动打开浏览器。

【不要关闭那个黑窗口】——它就是服务本身，关掉签到就停了。

默认地址是 http://127.0.0.1:8787 。如果 8787 被占用，程序会自动往后找
8791、8792……，实际地址看黑窗口里「控制台: http://...」那一行。

不想每次都弹浏览器：双击「静默启动.bat」，它只开服务不弹页面，
之后自己用收藏夹打开控制台。


二、第一次使用：添加账号
--------------------------------------------------
最快的方式是「官方登录」，不用复制任何东西：

1. 点右上角「添加账号」，默认就是「官方登录」标签
2. 点「微信扫码登录」——程序会在后台悄悄打开一个隐藏浏览器
   （不会弹窗），把官方登录页的二维码显示在弹窗里
3. 手机微信扫这个二维码，确认登录
4. 两秒内账号自动出现在列表里，隐藏浏览器自动关闭

想用手机号 / 企业微信 / QQ / 邮箱登录：点下面那个灰色按钮
「改用手机号 / 企业微信」，这次会弹出浏览器窗口，因为需要你输号码
和验证码。

如果这台电脑没装 Chrome 或 Edge（Windows 一般都自带 Edge），
可以改用「手动填写」自己粘令牌；或者「手机扫码」扫一下在手机上填。

卡片上会显示：今天是否已签到、连续天数、积分余额、签到累计。
   · 余额 = 你现在还能用的积分（比如 69.23）
   · 签到累计 = 本次签到活动累计发了多少（连续天数 × 每天 100）
   两个数不一样是正常的，别当成 bug。


三、自动签到
--------------------------------------------------
默认每天 08:30 / 12:00 / 15:00 / 18:00 / 21:30 各跑一次。
已经签过的账号会自动跳过，重复跑不会重复领积分，所以多点几次是安全的。

时间点可以在页面右下角「定时设置」里改，改完立刻生效。

注意：定时只在这个程序运行期间执行。想让它长期跑，做一下开机自启。


四、开机自启（可选）
--------------------------------------------------
按 Win+R，输入 shell:startup 回车，把「静默启动.bat」的快捷方式拖进去。
（拖 exe 也行，只是每次开机会弹浏览器）


五、数据在哪 / 怎么迁移
--------------------------------------------------
数据就在 exe 旁边的 data 文件夹：

  data\wb.db      账号、签到记录、设置
  data\.secret    加密令牌用的密钥

想换台电脑继续用，把整个文件夹（exe + data）一起拷过去就行。
令牌是用 .secret 里的密钥加密的，所以 .secret 不要单独发给别人。

如果换了电脑发现账号还在、但都提示「令牌失效」，
说明只拷了 wb.db 没拷 .secret，重新粘一次令牌即可。


六、常见问题
--------------------------------------------------
Q: 杀毒软件报毒 / 提示风险？
A: 单文件 exe 是 PyInstaller 打的包，容易被启发式引擎误报，属于常见误报。
   加信任即可；不放心就用「源码版」，装个 Python 直接跑，代码全在里面。

Q: 端口全被占用，起不来？
A: 命令行窗口里先设 WB_PORT=9000 再启动，或直接在启动脚本里加一行。

Q: 想加访问密码，防止同网段别人打开？
A: 设环境变量 WB_PASSWORD=你的密码 再启动，之后打开页面要先输密码。

Q: 点「微信扫码登录」提示找不到浏览器？
A: 官方登录需要这台电脑装了 Chrome 或 Edge。Windows 一般自带 Edge；
   实在没有就改用「手动填写」粘令牌。

Q: 积分数字和产品里看到的不一样？
A: 「余额」是当前可用积分，「签到累计」只是活动累计发放量。两个不同。

Q: 令牌多久过期？
A: 大约 28 天。过期后卡片会变红提示「令牌失效」，重新粘一次即可，
   历史签到记录不会丢。

Q: 提示「今日已签到」但积分没变？
A: 说明当天确实签过了，接口返回已签到状态，属于正常情况。
